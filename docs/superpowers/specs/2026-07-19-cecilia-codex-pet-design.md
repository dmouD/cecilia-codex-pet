# 塞西莉亚 Codex 互动宠物设计

## 目标

制作一个可在 Codex 中打开和互动的塞西莉亚 Q 版宠物。角色外观必须严格依照用户提供的参考图组制作，不采用自由改编式设计。新增参考图明确了此前不可见的全身服装结构，并覆盖旧规格中错误的长款奶油礼袍推断。宠物完整提供待机、眨眼、点击、思考、写代码、完成和报错状态。近景参考图中的粉色团子只作为偶发互动伙伴出现，不取代塞西莉亚主体。

第一版以自包含的互动页面交付，可直接在 Codex 中预览和操作。由于独立页面无法读取 Codex 应用内部任务状态，第一版通过自动演示和显式状态控制器展示所有状态，同时公开统一的 `setState()` 接口，为后续接入可用的 Codex 状态桥保留稳定边界。

## 视觉设计

### 角色基准

- 形态：正面或轻微三分之二视角的全身 Q 版，约 2.5 头身，适合在 240–320 像素高的区域清晰显示。
- 参考角色分工：新增第 4 张全身持花图是全身服装与腿部比例的主参考；新增第 5 张近景图是脸部、兜帽配色与简化线条画风的主参考；新增第 1、2 张用于核对兜帽披风的层次和奶油色褶边；新增第 3 张用于核对披风下的白色上衣、深色裙装和发型结构。此前视觉伴侣页面中的示意造型不进入正式素材。
- 不可漂移的识别特征：奶油色外层兜帽、深灰黑色兜帽内衬与后侧发层、灰橄榄色前发、参考图一致的刘海分束和单侧长发轮廓、圆润脸部比例、酒红色线状闭眼、粉色斜线腮红、小幅张嘴笑容、奶油与深灰黑主配色。
- 正确全身服装：外层为奶油色滚边和浅色补片的深灰黑兜帽披风；披风下为奶油色高领褶边上衣与宽袖、深色短裙或连衣裙层、浅色裙摆褶边、深灰黑长袜和小号深色鞋。不得再次生成拖到脚面的长款奶油礼袍。
- 画风：严格贴近参考图的柔软手绘日系 Q 版表现，使用相近的深色略抖轮廓线、扁平低饱和上色、极少量柔和阴影和简化五官；不升级为精细厚涂或常规商业立绘风格。
- 禁止项：改变刘海结构或头发长度关系、改变兜帽黑白分区、改变脸型和五官比例、把奶油色外层延展成长袍、遮掉正确的深色短裙和长袜、写实比例、3D 渲染、复杂背景、文字、水印、花束、围巾、雪人、额外人物、持续抱着粉色团子、明显偏离参考图的发色或服装配色。

### 还原审核门

正式生成分为两个阶段：

1. 仅生成一张标准全身主立绘预览，并按参考角色分工逐项核对发型、兜帽、脸型、表情、线条、全身服装结构和配色。
2. 将主立绘展示给用户确认。用户明确通过前，不生成其他状态素材；若用户指出差异，每轮只修正已指出的差异并重新核对。

主立绘通过后，所有状态图都必须以该主立绘为编辑目标制作，不能重新独立设计角色。

### 粉色团子

粉色团子不是常驻主体，只在以下事件中出现：

- 完成状态有一定概率跑入画面并被塞西莉亚抱住。
- 连续点击触发一次短暂彩蛋。
- 长时间待机时以低概率从边缘探头。

其他状态不显示团子，保证塞西莉亚始终是视觉中心。

## 状态与动作

| 状态 | 角色表现 | 页面动画 |
| --- | --- | --- |
| `idle` | 自然站立，默认保持参考图中的温柔闭眼微笑 | 轻微呼吸、发梢摆动；偶尔短暂睁眼后重新眨回笑眼 |
| `thinking` | 歪头，手指轻抵唇边 | 小光点缓慢浮动，身体轻微左右摇摆 |
| `coding` | 抱着深色小代码板敲击 | 手部节奏运动，代码板微光闪烁 |
| `success` | 开心跳起或双手庆祝 | 金色星花弹出；粉色团子偶发入场 |
| `error` | 眼角含泪，兜帽微垂 | 轻微缩起，代码板出现无文字的红色叉形符号 |
| `clicked` | 脸红、挥手或轻晃 | 短促弹跳后回到先前状态 |
| `sleeping` | 闭眼安静蜷坐 | 缓慢呼吸；长时间无操作后进入 |

连续点击彩蛋临时覆盖当前动作，播放结束后恢复之前的工作状态。状态切换采用短交叉淡化，避免人物瞬间跳变。

## 素材策略

采用“主立绘 + 状态变体 + 网页动画”的混合方案：

1. 使用第一张参考图生成一张高一致性的标准全身 Q 版主立绘，优先还原角色而不是增加创意细节。
2. 经用户审核通过后，以主立绘作为编辑目标生成思考、写代码、完成、报错和睡眠变体，锁定脸型、五官位置、刘海分束、头发长度关系、兜帽分区、服装结构、线条风格和配色。
3. 眨眼、呼吸、浮动、轻晃、光点和星花由 CSS/网页动画实现，减少重复素材并保持角色一致。
4. 最终项目使用透明背景 PNG；生成阶段优先使用纯色键控背景并在本地移除背景。若复杂发丝导致去背质量无法通过验证，再向用户说明并征得同意后使用原生透明度生成路径。

## 页面结构

页面由四个边界清晰的模块组成：

- `PetStage`：渲染角色、团子和粒子层，只消费当前状态，不决定状态。
- `PetStateMachine`：管理工作状态、临时点击动作、睡眠计时和恢复规则。
- `InteractionController`：处理单击、连续点击、拖动和状态控制器输入。
- `DemoController`：在未接入外部状态时循环演示全部状态；外部调用 `setState()` 后暂停自动演示。

页面默认使用适配 Codex 深色界面的透明感舞台，不嵌入远程资源，不上传参考图或用户数据。布局在窄窗口下仍保持角色完整可见。

## 状态接口与数据流

公开接口为：

```js
window.ceciliaPet.setState('idle' | 'thinking' | 'coding' | 'success' | 'error' | 'sleeping')
```

数据流为：状态控制器或自动演示调用 `setState()` → `PetStateMachine` 验证状态并更新 → `PetStage` 选择对应角色素材和动画类 → 动画完成后根据规则保持新状态或恢复先前状态。

页面不宣称能够自行读取 Codex 私有任务状态。后续若存在允许的状态桥，只需调用同一接口，不需要改动角色渲染或交互模块。

## 异常与降级

- 未知状态值：忽略并保留当前状态，同时在开发控制台记录一次警告。
- 状态素材加载失败：回退到主立绘和对应 CSS 基础动画，页面仍可互动。
- 用户启用“减少动态效果”：关闭循环摇摆、粒子和弹跳，只保留淡化切换。
- 小尺寸窗口：隐藏文字状态控制器，保留图标控制和角色舞台。
- 去背边缘出现明显色边或发丝缺失：素材不进入项目，先重试一次键控参数；仍失败则暂停并征求原生透明生成许可。

## 验收标准

- 主立绘需通过逐项参考审核：脸部与画风贴近近景参考，完整服装贴近全身参考；发型外轮廓与刘海分束、兜帽黑白分区、奶油上衣和宽袖、深色短裙层、浅色褶边、深色长袜与小鞋均保持高一致性。
- 未获得用户对主立绘的明确通过，不得生成其他状态素材或进入页面整合。
- 塞西莉亚是常驻主体，粉色团子只按规定偶发出现。
- 六个持久状态均可在控制器中触发，自动演示可完整轮播主要工作状态；单击可独立触发 `clicked` 临时状态。
- 点击与连续点击彩蛋结束后能恢复到正确的工作状态。
- 在常见 Codex 深色界面和 240–320 像素角色高度下轮廓清晰。
- 页面离线可用，不依赖远程图片、字体或脚本，不读取或发送用户数据。
- `prefers-reduced-motion` 下不存在持续大幅动画。
- 素材路径失效时页面有主立绘降级，不出现空白舞台。

- 素材提示词记录与本地运行说明。
